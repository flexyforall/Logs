Drop the new playing cards here (PNG/WebP/SVG).

Any of these works:
- one file per card, named by rank and suit, e.g. `7H.png`, `10S.png`, `JD.png`, `AC.png`
  (ranks 7 8 9 10 J Q K A, suits C D H S), plus `back.png` for the card back;
- or a single sheet with all 32 faces (and the back), like the current `../cards.webp`.
